# Cart Rush

Аркада-catcher: тележка едет по рельсам склада и ловит падающие коробки. Рельсы две — задняя,
куда падают только синие коробки, и передняя, куда падают только жёлтые. Пойманное не исчезает,
а остаётся в кузове физическим грузом, который раскачивается на манёврах и может вывалиться
за борт. Пробел сдаёт груз в очки: чем больше
коробок в одной сдаче, тем дороже каждая.

**▶ [Играть](https://023irene.github.io/cart-rush/)**

## Управление

| Клавиша | Действие |
|---|---|
| `←` / `→` (или `A` / `D`) | Везти тележку вдоль рельсы |
| `↑` / `↓` (или `W` / `S`) | Сменить рельсу: задняя / передняя |
| `Пробел` | Сдать груз |
| `Esc` / `P` | Пауза |

## Запуск локально

```
npm install
npm run dev
```

Собранная версия — `npm run build` и затем `npm run preview`. Сборка самодостаточна:
в `dist/` нет ни одного внешнего адреса, игра работает без интернета.

## Стек

Phaser 4.2.1 с физикой Matter, сборка Vite, Phaser из npm. Код разложен по модулям в `src/`.
Выбор движка — [ADR-0001](docs/architectural-decisions/0001-engine-and-stack.md),
сборка — [ADR-0011](docs/architectural-decisions/0011-vite-build.md).

Все игровые числа собраны в объект `CONFIG` в `src/config.js` — баланс крутится только там.
Зависимостей у игры ровно две: `phaser` и `vite`, любая третья требует нового ADR.
