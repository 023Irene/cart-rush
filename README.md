# Cart Rush

Аркада-catcher: тележка едет по рельсам склада и ловит падающие коробки. Рельсы две — задняя,
куда падают только синие коробки, и передняя, куда падают только жёлтые. Пойманное не исчезает,
а остаётся в кузове физическим грузом, который раскачивается на манёврах и может вывалиться
за борт. Пробел сдаёт груз в очки: чем больше
коробок в одной сдаче, тем дороже каждая.

**▶ [Играть](https://023irene.github.io/cart-rush/)**

## Управление

| Клавиша | Действие |
|---|---|
| `←` / `→` (или `A` / `D`) | Везти тележку вдоль рельсы |
| `↑` / `↓` (или `W` / `S`) | Сменить рельсу: задняя / передняя |
| `Пробел` | Сдать груз |
| `Esc` / `P` | Пауза |

## Запуск локально

VS Code → правый клик по `index.html` → **Open with Live Server**.

Двойной клик по файлу не работает: Phaser грузит аудио через `fetch`, а на протоколе `file://`
браузер блокирует такие запросы по CORS. Игра в этом случае откроется, но будет молчать —
в консоли появится предупреждение.

## Стек

Phaser 4.2.1 с физикой Matter, один файл `index.html`, Phaser подключается с CDN, сборки нет.
Обоснование и триггеры пересмотра — [ADR-0001](docs/architectural-decisions/0001-engine-and-stack.md).

Все игровые числа собраны в объект `CONFIG` в начале `index.html` — баланс крутится только там.
