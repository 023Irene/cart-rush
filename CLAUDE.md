# Cart Rush — правила проекта

Бесконечная аркада-catcher: тележка ездит по двум рельсам — задней (синей) и передней
(жёлтой) — и ловит падающие коробки своего цвета.

## С чего начинать сессию

1. `docs/STATE.md` — где остановились и что проверить.
2. `docs/gameplan.md` — следующий незакрытый этап.
3. `GAME_SPEC.md` — источник истины по механикам и числам.

## Стек — не переоткрывать

Phaser 4.2.1 + Matter, сборка **Vite**, Phaser из npm, код по модулям в `src/`.
Движок — `docs/architectural-decisions/0001-engine-and-stack.md`,
сборка — `docs/architectural-decisions/0011-vite-build.md`.

Зависимостей ровно две: `phaser` и `vite`. Любая третья (TypeScript, UI-фреймворк, плагин
Vite, сервер, аналитика) требует нового ADR, а не тихого `npm i`.

## Запуск

```
npm install     # один раз
npm run dev     # игра на http://localhost:5173
```

Собранное — `npm run build`, затем `npm run preview`.

Открывать `index.html` файлом больше нельзя и не нужно: там теперь только оболочка,
код грузится модулями. Заодно исчезла старая ловушка проекта — по `file://` браузер
блокировал сэмплы из `assets/audio/` по CORS, и игра молча шла без звука.

## Код

- Все игровые числа — в объекте `CONFIG` в `src/config.js`. Баланс крутится только там.
- Комментарии по-русски над блоками. Имена файлов, классов, переменных — по-английски.
- Кириллица в путях ломает инструменты: имена файлов и папок только латиницей.
- Каждый этап заканчивается запускаемой сборкой. «Собирается без ошибок» не считается.

## Что НЕ делать

Раздел 16 спеки (Anti-scope). Закрыты: слизь и помехи обзору, мультиплеер, туториал-сцена,
множитель серии, больше двух рельс, секции в кузове, фоновая музыка, скины и косметика.
Всё отложенное живёт в `docs/backlog.md`.

Открывать пункты можно **только новым ADR**, как уже сделано: бустеры и настройка громкости —
ADR-0009 (этапы 8.5 и 8.6), дебафф «Тормоз» — ADR-0010 (этап 8.7), спрайты — этап 10,
лидерборд — этап 12.

## После каждого этапа

Обновить `docs/STATE.md` и `PROGRESS.md`, затем коммит conventional-стилем на русском
(`feat: добавил сдачу груза`). `git push` — только по явной команде.
