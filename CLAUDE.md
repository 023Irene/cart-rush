# Cart Rush — правила проекта

Бесконечная аркада-catcher: тележка ездит по двум рельсам — задней (синей) и передней
(жёлтой) — и ловит падающие коробки своего цвета.

## С чего начинать сессию

1. `docs/STATE.md` — где остановились и что проверить.
2. `docs/gameplan.md` — следующий незакрытый этап.
3. `GAME_SPEC.md` — источник истины по механикам и числам.

## Стек — не переоткрывать

Phaser 4.2.1 + Matter, один файл `index.html`, Phaser с CDN, сборки нет.
Решение и триггеры его пересмотра — `docs/architectural-decisions/0001-engine-and-stack.md`.

Единственная зависимость — Phaser. Любая другая (TypeScript, UI-фреймворк, сборщик, сервер,
аналитика) требует нового ADR, а не тихого добавления.

## Запуск

VS Code → правый клик по `index.html` → **Open with Live Server**.
Двойной клик по файлу не работает: с этапа 4 в игре есть звук из `assets/audio/`, Phaser грузит
его через `fetch`, а `file://` браузер блокирует по CORS. Без сервера игра молча не запустится.

## Код

- Все игровые числа — в объекте `CONFIG` в начале `index.html`. Баланс крутится только там.
- Комментарии по-русски над блоками. Имена файлов, классов, переменных — по-английски.
- Кириллица в путях ломает инструменты: имена файлов и папок только латиницей.
- Каждый этап заканчивается запускаемой сборкой. «Собирается без ошибок» не считается.

## Что НЕ делать

Раздел 16 спеки (Anti-scope) — список закрыт. Коротко: три бустера из концепции, слизь,
лидерборд, мультиплеер, туториал-сцена, множитель серии, больше двух рельс, секции в кузове,
спрайты, музыка, скины. Всё отложенное живёт в `docs/backlog.md`.

## После каждого этапа

Обновить `docs/STATE.md` и `PROGRESS.md`, затем коммит conventional-стилем на русском
(`feat: добавил сдачу груза`). `git push` — только по явной команде.
