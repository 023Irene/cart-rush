# Концепция игры

## Основная идея

Бесконечный раннер на рельсах, где игрок управляет тележкой и должен собирать падающие коробки, сохраняя её XP и набирая как можно больше очков.

## Игровая механика

- Тележка имеет определённый запас **XP**, например **500 XP**.
- Сверху падают **жёлтые и синие коробки разных размеров**.
- **Синие коробки** падают на заднюю часть тележки.
- **Жёлтые коробки** падают на переднюю часть тележки.
- Стрелки **↑ / ↓** позволяют переключаться между рельсами.
- Каждая коробка отнимает определённое количество XP:
  - маленькая коробка → **−30 XP**
  - средняя коробка → **−80 XP**
  - большая коробка → **−150 XP**
- Если XP тележки достигает **0**, наступает **Game Over**.
- Чем больше коробок игрок успевает собрать/обработать, тем выше **множитель очков ×** и итоговый счёт.
- **Пробел** активирует механику очистки: коробки исчезают, а игрок получает бонус к очкам/множителю.

## Бонусы

Во время забега появляются бустеры:

- **Щит** — защищает от негативного эффекта.
- **Восстановление XP** — возвращает часть XP тележки.
- **Ускорение** — временно увеличивает скорость.
- **Замедление времени** — временно замедляет падение объектов.

Всего предусмотреть **3–4 активных бустера**.

## Усложнители

Во время забега появляются опасные объекты:

- Бомбы.
- Слизь.
- Другие препятствия и негативные объекты.

Они могут дополнительно уменьшать XP, мешать управлению или нарушать обычный игровой ритм.

## Прогрессия

Игра является **бесконечной**:

- скорость постепенно увеличивается;
- объекты появляются чаще;
- увеличивается количество препятствий;
- комбинации объектов становятся сложнее;
- игрок стремится установить новый рекорд.

## Система XP

XP тележки является её основным ресурсом и фактически определяет продолжительность забега.

**Пример:**

`500 XP → маленькая коробка −30 XP → 470 XP`

`470 XP → большая коробка −150 XP → 320 XP`

`320 XP → несколько коробок → XP постепенно уменьшается`

При достижении **0 XP** игра заканчивается.
