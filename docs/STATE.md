## Что проверить перед продолжением

1. Игра открывается: правый клик по `index.html` → Open with Live Server.
2. `↑`/`↓` переключают рельсу за 0.15 с.
3. Коробки ловятся в кузов и остаются там физическими телами.
4. Резкая смена рельсы раскачивает груз, часть коробок вылетает за борт.
5. Консоль браузера (F12) чистая.
