# ADR-0001. Движок и стек Cart Rush

- **Дата:** 2026-08-13
- **Статус:** принято
- **Решает:** на чём делать Cart Rush и как запускать проект

## Контекст

Cart Rush — бесконечная аркада-catcher: тележка на двух рельсах ловит падающие коробки в две
секции. Полное описание — в `GAME_SPEC.md`.

Из интервью по спеке пришли два требования, которые определяют выбор:

1. **Настоящая физика груза** (спека, раздел 5.5). Пойманные коробки не исчезают, а лежат в
   кузове физическими телами: раскачиваются при смене рельсы, толкают друг друга и могут
   вывалиться за борт. Это визитная карточка игры, а не украшение.
2. **Мобильный браузер наравне с десктопным** (раздел 2). Нужен корректный ресайз канвы под
   произвольный экран и ввод свайпом.

Обе ветки стека рассматривались всерьёз:

| Ветка | За | Против |
|---|---|---|
| vanilla JS + Canvas 2D | один файл, офлайн, ноль зависимостей, полный контроль | физику стека тел, менеджер сцен, звук и ресайз пришлось бы писать руками — это и есть основной объём работы |
| Phaser 4 + Matter | физика, сцены, звук, ресайз и частицы из коробки | чужой API, npm или CDN, меньше понимания того, что происходит под капотом |

## Решение

**Phaser 4.2.1 с физикой Matter, один файл `index.html`, Phaser подключается с CDN, запуск через
VS Code Live Server.**

- Версия закреплена точным номером: `https://cdn.jsdelivr.net/npm/phaser@4.2.1/dist/phaser.min.js`.
  Не `@4` — плавающая мажорная ссылка ломает проект молча.
- Сборки нет: ни npm, ни Vite, ни бандлера.
- Единственная внешняя зависимость — Phaser.
- Все игровые числа — в объекте `CONFIG` в начале файла.

## Почему не двойной клик по index.html

Обычно ванильные проекты открываются двойным кликом, и это было бы удобнее всего. Здесь так не
получится: Phaser грузит аудио через `fetch`, а на протоколе `file://` браузер блокирует такие
запросы по CORS. Игра запустилась бы, но без звука и без ассетов.

Поэтому запуск: **VS Code → правый клик по `index.html` → Open with Live Server**. Это единственная
известная команда запуска проекта.

## Цена решения

Принимаем осознанно:

- **Тюнинг физики.** Массы, трение, отскок и импульсы придётся подбирать руками. Если груз за два
  вечера не приручится (прилипает, дрожит, проваливается сквозь дно) — падаем на упрощённую
  инерцию без Matter. Это заранее описанный запасной путь, не провал.
- **Чужой API.** Часть кода будет «как принято в Phaser», а не «как понятнее новичку». Для
  свежей документации по API подключён MCP-сервер `context7` (`.mcp.json`).
- **Интернет при каждом запуске.** Phaser тянется с CDN. Если станет мешать — скачать
  `phaser.min.js` в `assets/` и заменить ссылку; ADR при этом не меняется.
- **Один файл будет расти.** С пятью сценами, магазином и физикой это несколько сотен строк
  сразу.

## Триггеры переоткрыть это решение

Перечислены явно, чтобы не спорить об этом каждую сессию:

1. `index.html` перевалил за **1500 строк** → переходим на Vite с папками `scenes/`, `systems/`,
   `config.js`. Движок при этом остаётся тот же.
2. Физика Matter не приручилась за два вечера → упрощённая инерция, возможен возврат на
   ванильный Canvas.
3. Понадобилась любая зависимость кроме Phaser (TypeScript, UI-фреймворк, сервер, аналитика) →
   отдельное решение, ADR-0002.

## Последствия

- Скаффолдер Phaser не используется: он рассчитан на npm-проект, а у нас один файл.
- Публикация: достаточно выложить `index.html` и `assets/` на любой статический хостинг.
- Все последующие сессии читают этот файл и не переоткрывают выбор движка без триггера выше.
