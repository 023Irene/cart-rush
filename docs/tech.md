## Запуск

**Опубликованная версия:** https://023irene.github.io/cart-rush/ — раздаётся GitHub Pages из
ветки `main`, обновляется автоматически при каждом push.

**Локально:**

```
VS Code → правый клик по index.html → Open with Live Server
```

Двойной клик по файлу **не работает**: на протоколе `file://` браузер блокирует загрузку аудио
по CORS. Если расширения Live Server нет — установить `ritwickdey.LiveServer` из Marketplace.

## Устройство index.html

Порядок секций в файле:

1. `<style>` — сброс полей, фон страницы, обёртка `#game` во всё окно.
   Центрированием занимается только Phaser (`CENTER_BOTH`): флекс на `body` давал второе
   центрирование поверх первого и уводил канвас за край экрана.
2. `CONFIG` — **все** игровые числа: размеры, скорости, штрафы, ценности, параметры физики.
   Баланс крутится только здесь, логику для этого трогать не нужно.
3. `SaveManager` — чтение и запись `localStorage`, ключ `cartRushSave`.
4. Сцены: `BootScene` → `MenuScene` → `GameScene` → `PauseScene` → `GameOverScene`.
5. `new Phaser.Game(...)` — запуск.

## Физика

- Движок Matter, гравитация только по Y.
- Тележка — статичное составное тело (дно и два борта, без перегородки). Двигается дельтами
  через `Body.translate`, поэтому не отталкивается коробками.
- **Положение тележки хранится в `this.cart` (сцена), а не читается из `cartBody.position`.**
  У составного тела Matter `position` — это центр масс: если рисовать от него, графика и физика
  разъезжаются (в первой версии — на 21 px).
- **Рельсы разведены категориями столкновений** (`CAT.fall` / `CAT.cart` × две рельсы). Коробка
  чужой рельсы пролетает сквозь тележку, падающие коробки не сталкиваются друг с другом в
  воздухе. Это самая хрупкая часть: при странностях с ловлей включать `CONFIG.debug`.
- Коробки — динамические тела. При первом касании тележки **или уже лежащего груза** коробка
  помечается как груз и остаётся в кузове. Секций нет, ничего не уничтожается.
- Перспектива: тела и картинки масштабируются на `rail.scale`. `setScale` у Matter-объекта
  Phaser масштабирует и картинку, и тело, причём сбрасывает предыдущий масштаб — накопления
  погрешности нет. Тело тележки при смене рельсы пересобирается заново.
- Импульс грузу при манёврах задаётся вручную (`setVelocity`), а не выводится из движения
  тележки: так поведение предсказуемо и настраивается одним числом в `CONFIG`.

## Отладка

- `CONFIG.debug = true` включает отрисовку тел Matter поверх графики.
- Счётчик FPS — встроенный в браузер (Chrome DevTools → Rendering → Frame rendering stats).

## MCP

`.mcp.json` подключает сервер `context7` — свежая документация по API Phaser вместо памяти
модели. MCP читается только при старте сессии: после правки файла сессию надо перезапустить.
