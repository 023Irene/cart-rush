# PROGRESS — Cart Rush

## Сделано

### 2026-08-13 — старт проекта

- Пройдено интервью по спеке, блоки 1–11 (полный режим). Две правки к исходной концепции:
  XP теперь отнимается только за ошибки, а роль ограничителя играет физика груза, а не
  вместимость тележки.
- `GAME_SPEC.md` — спека из 20 разделов, источник истины по механикам и числам.
- ADR-0001: движок **Phaser 4.2.1 + Matter**, один файл `index.html`, Phaser с CDN, запуск через
  Live Server. Записаны цена решения и триггеры его пересмотра.
- Документы проекта: `docs/gameplan.md`, `docs/tech.md`, `docs/STATE.md`, `docs/backlog.md`,
  `CLAUDE.md`, `AGENTS.md`, `.mcp.json` (context7), `.gitignore`.
- **Этап 1 — каркас** (`index.html`, ~780 строк): объект `CONFIG` со всеми числами,
  `SaveManager`, пять сцен (Boot, Menu, Game, Pause, GameOver), физика Matter, две рельсы,
  тележка составным телом с двумя секциями, падающие коробки трёх размеров и двух цветов,
  ловля с определением секции, физический груз в кузове, раскачка при манёврах, потеря груза
  за борт.
